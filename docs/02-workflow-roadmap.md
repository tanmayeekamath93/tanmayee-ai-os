# Workflow Roadmap

This repo should evolve in phases so it stays reusable without becoming an unmaintained prompt dump.

## Phase 1: Foundation

- define personal AI operating principles
- create a small set of core skills
- set up naming conventions and folder structure
- establish evaluation rubrics for your most common use cases

## Phase 2: Task automation

- add reusable templates for common work loops
- define MCP/tool entry points for daily tasks
- capture frequently used prompts and safe defaults

## Phase 3: Quality loop

- add evaluation prompts and pass/fail criteria
- store examples of strong and weak outputs
- refine skills based on observed mistakes

## Phase 4: Mature personal system

- reduce repeated prompt overhead
- keep a curated library of proven patterns
- maintain a living inventory of what is production-ready vs experimental

## Design principle

Every prompt, skill, or tool should answer one question: "Does this reduce repeated instructions while increasing quality or speed?"
