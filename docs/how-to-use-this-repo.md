# How to use this repo

This repository is designed to serve as your reusable AI operating system for day-to-day work.

## Default workflow

1. Pick the relevant skill or template.
2. Add the task-specific context.
3. Ask the AI to operate within the repo's default guardrails.
4. Evaluate the output with the rubric when quality matters.
5. Save any strong pattern back into the repo for reuse.

## Best practices

- Keep prompts modular.
- Prefer reusable patterns over ad hoc instructions.
- Store outputs that work well as reusable assets.
- Update the repo as your real workflow matures.

## Recommended usage by task type

### Product / research work
- start with `skills/pm-research-workflow.md`
- use `templates/decision-memo.md` or `templates/research-brief.md`

### Engineering handoff and specs
- use `skills/engineering-spec-author.md`

### Leadership communication
- use `skills/customer-learnings-to-leadership.md`
- use `templates/leadership-feature-review.html`

### Reuse-ready golden workflows
- use `skills/golden-workflows.md`

### Quality check
- use `evals/ai-quality-rubric.md`

### MCP pattern library
- review `mcp/README.md` and add patterns there when they become part of your regular workflow
