# MCP patterns

This folder is reserved for reusable MCP-related patterns, tool definitions, and integration notes you want to keep as part of your personal AI system.

## Intended use

Add small, practical MCP config examples and tool wrappers here when they become part of your regular workflow.

## Starter guidance

- Keep each MCP definition focused on one job-to-be-done.
- Prefer reusable, low-noise tool wrappers.
- Document tool purpose, inputs, and expected outputs.
- Track only the MCP patterns you use repeatedly.

## Example categories

- product / research tools
- engineering / repo tools
- documentation / writing tools
- leadership reporting tools
- evaluation or validation tools
